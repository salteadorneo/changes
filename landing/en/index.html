Watch your pages and get notified when content or appearance changes. A screenshot is stored on every change, compared side by side with the previous one, and the change is reported as a GitHub Issue. No server, no external dependencies.

Features

Everything essential, already done.

Capture only on change

Initial shot on day one, then only when a real change is detected. No filler captures.

Visual before/after compare

Each page shows two shots at 50% width side by side, with arrows to browse the history.

GitHub Issue per change

Every change opens or comments an issue, in the configured language (Spanish or English).

Screenshots outside the repo

State and images live in the Actions cache. Nothing generated is ever committed.
