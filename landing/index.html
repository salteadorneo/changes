Detecta el cambio.
Guarda la prueba.

Revisa tus páginas y avisa cuando cambian el contenido o la apariencia. Captura una captura de pantalla en cada cambio, compara lo de antes con lo de ahora y anuncia el cambio como un issue. Sin servidor propio ni dependencias externas.

Cómo funciona

Tres pasos. Sin servidores.

01

Define tus fuentes

Una fila por URL en config.yml: CSS, XPath, JSONPath o el HTML entero.

02

Captura en cada cambio

Una captura el primer día y otra solo cuando algo se mueve. Deja el rastro visual antes y después.

03

Publica el resultado

Un dashboard generá un issue en GitHub por cada cambio. Los datos antiguos se podan para que el sitio siga ligero.

Resiliente por defecto.

  • ·Tolera verificaciones anti-bot (Cloudflare, captcha) y banners de cookies.
  • ·Sin hashes ni diff de texto publicado: el evento es lo que importa, no el estado.
  • ·Capturas persistidas en caché de Actions, nunca en el repositorio.
  • ·Interfaz en español e inglés, textos centralizados en lang/*.json.
De cero a publicado

Un solo archivo de configuración.

  1. Usa la plantilla en GitHub.
  2. Rellena config.yml con tus fuentes.
  3. Activa GitHub Pages en los ajustes del repositorio.
  4. Lanza el workflow manualmente la primera vez.
